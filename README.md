# GitHub Pages Jekyll Starter

This is a simple starter site for GitHub Pages using Jekyll.

## Publish steps

1. Create a GitHub repo (e.g. `yourusername.github.io` or `my-site`)
2. Copy these files into that repo
3. Commit and push to `main`
4. In **Settings → Pages** choose:
   - Source: **Deploy from a branch**
   - Branch: `main`
   - Folder: `/ (root)`
5. Wait for deployment, then open your site URL
